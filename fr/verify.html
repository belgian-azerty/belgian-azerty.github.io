Votre téléchargement est-il correct ?

Chaque version est accompagnée d'un fichier SHA256SUMS. Il contient l'empreinte de chaque fichier. Si votre empreinte correspond, votre fichier n'a pas été modifié en chemin.

Sous Linux, dans le dossier qui contient les fichiers :

sha256sum -c SHA256SUMS --ignore-missing

Chaque fichier doit afficher OK.

Sous Windows (PowerShell), fichier par fichier :

Get-FileHash .\belgian-azerty-windows_0.9.10_all.deb -Algorithm SHA256

Comparez le long code avec la ligne de ce fichier dans SHA256SUMS.

Ça ne correspond pas ? N'utilisez pas le fichier. Téléchargez-le à nouveau depuis la page de la version.
