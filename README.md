# belgian-azerty.github.io

The website of [belgian-azerty-linux](https://github.com/belgian-azerty/belgian-azerty-linux): Belgian AZERTY that
works as it does on Windows, for Linux Mint and Zorin OS. Dutch, French and English.

Plain HTML and one stylesheet. No JavaScript, no cookies, no tracking, and no requests to other sites: the fonts
(Space Grotesk, IBM Plex Sans, JetBrains Mono) are stored here under the SIL Open Font License, see `assets/fonts/`.

Built with AI help (Claude). Not affiliated with Linux Mint or Zorin OS. A small volunteer project.
